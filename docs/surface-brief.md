# FrameKeeper workspace

Mode: Operate. The user is an independent AI video creator checking a single scene before generating multiple shots. The task is to spot continuity drift, repair it, and copy a reliable prompt.

## Direction contract

**THESIS:** This is a working continuity sheet. The main visual event is a shot sequence that reveals exactly where the same scene changes by accident. It avoids a generic dashboard of summary cards.

**OWN-WORLD:** Use a pale blue-gray studio work surface, deep charcoal ink, sea-glass teal for approved continuity, and signal coral for drift. Hairline dividers, ruled fields, large shot numbers, and compact editorial labels borrow from a script breakdown sheet. Controls are square-edged and precise. Dense work areas stay quiet.

**STORY:** The user sees a five-shot synthetic example, notices two drift marks in the sequence, opens one shot, sees the field and expected value, corrects it, then copies a prompt that carries the approved anchors. The scene remains editable and exportable.

**FIRST VIEWPORT:** A slim masthead sits above an editable scene title. Below it, a full-width horizontal strip of shot numbers and short actions acts as both navigation and continuity map. The first shot editor and the continuity bible share the remaining viewport in a 2:1 layout. The issue details and prompt are visible without an introduction panel.

**FORM:** Third of seven grounded systems: a continuity supervisor's script breakdown sheet. Seed `c43227a1`, assigned. Signature interaction: changing a shot field changes its mark in the sequence, the issue list, and the locked prompt. One brief status transition reinforces that linked update; reduced motion removes it.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance

## Grounded directions considered

1. Film script sides with marginal revision marks.
2. Editor decision list with timecode rows.
3. Continuity supervisor's script breakdown sheet — selected.
4. Production call sheet with daily sections.
5. Camera slate metadata log.
6. Rehearsal blocking board.

The selected form matches the daily work of comparing shot details against an approved bible. A type specimen would obscure the editing task. Airline coupons would make shot order clear but imply finality when creators need to revise. The botanical overlay suggests useful alignment, retained as a quiet rule: every shot repeats the same anchor field order.
